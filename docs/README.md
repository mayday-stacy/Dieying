# Dieying user guide

Dieying is a Windows-first layer-based image editor for compositing and retouching, based on [Composa](https://github.com/dvdstelt/Composa). This guide adapts the upstream guide for the independent fork and retains its detailed descriptions of the shared editing tools. See the [project README](../README.md) for development status and limitations.

This guide describes what Dieying can do and how to do it. It is written for people who use the application; nothing here requires knowing how it is built.

## Conventions

Menu labels below use the English interface; Help > Language switches between English and Simplified Chinese after a restart. Keys are written for Windows and Linux: Ctrl, Alt and Shift. Menu paths are written as File > Open. Where a dialog or a field has a name, it is quoted as it appears on screen. Sizes are in pixels unless a unit is given.
